# CS 320 Portfolio

## Reflection

### How can I ensure that my code, program, or software is functional and secure?

I can ensure that my software is functional by testing it against the requirements and making sure both valid and invalid inputs are handled correctly. During this course, I used JUnit tests to verify that the different services worked as expected and followed the given requirements. Testing helped me identify potential errors and make sure the program behaved correctly. To help keep software secure, I can validate inputs, follow requirements carefully, and prevent invalid or unexpected data from being accepted by the program.

### How do I interpret user needs and incorporate them into a program?

I interpret user needs by reviewing the requirements and turning them into specific features and rules that the program needs to follow. For example, the contact service included requirements for contact IDs, names, phone numbers, and addresses. I used these requirements when developing the program and creating unit tests. This helped ensure that the program met the requirements and worked the way it was intended to.

### How do I approach designing software?

I approach software design by breaking a larger problem into smaller parts and determining what each part of the program needs to accomplish. I try to organize my code so that each class and method has a clear purpose. I also learned the importance of thinking about testing throughout development instead of waiting until the program is finished. This course helped me understand how software design and testing work together to create programs that are functional, organized, and easier to maintain.
